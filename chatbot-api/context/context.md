## 자기소개 / 한줄 소개

물류 현장에서 4년간 일하며 반복 업무 속에서도 프로세스를 개선하는 일에 흥미를 느꼈고, 기술로 더 나은 사용자 경험을 만들고 싶다는 목표로 SSAFY 12기에 합류해 프론트엔드 개발자로 전향했습니다.

React와 JavaScript를 기반으로 4개의 팀 프로젝트를 수행하며 컴포넌트 설계, 상태 관리, 실시간 통신, AI 모델 연동까지 폭넓게 경험했습니다. 그 중 두 프로젝트에서 프론트엔드 팀장을 맡아 구조 설계와 일정 관리를 주도했습니다.

특히 손 인식 모델을 활용해 브라우저에서 실시간 수어 입력기를 직접 구현한 경험과, FSD(Feature-Sliced Design) 아키텍처로 유지보수성과 확장성을 고려한 설계 경험을 통해, 단순 기능 구현을 넘어 문제를 끝까지 풀어내는 개발자로 성장하고 있습니다.

**Q: 팀 프로젝트에서 리더 경험이 있나요?**
